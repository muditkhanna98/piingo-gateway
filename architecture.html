API Gateway
:8081 · piingo-gateway
Single entry point. Validates JWTs via Azure AD B2C, strips incoming X-* headers, injects X-Gateway-Secret + identity headers, routes to services via Eureka. Serves aggregated Swagger UI.
OAuth2 WebFlux Spring Cloud Gateway
👤
User Service
:8080 · user-service
Manages user profiles. Provisions users on first login via JWT sub claim. Trusts X-Gateway headers — no JWT parsing. Stores users and online status in PostgreSQL.
Spring MVC PostgreSQL Flyway
💬
Chat Service
:8082 · chat-service
Manages conversations and participants. Creates conversations via POST /conversations; stores participant subs as text. Trusts X-Gateway headers identical to user-service.
Spring MVC PostgreSQL Flyway

Security flow

01
Azure AD B2C issues token
Client authenticates via PKCE / OIDC flow
02
Client sends request to gateway
Authorization: Bearer <jwt>
03
Gateway validates JWT signature
Verified against Azure AD B2C OIDC issuer endpoint
04
IdentityHeaderFilter strips & injects headers
Removes incoming X-* headers; adds X-Gateway-Secret · X-User-Sub · X-User-Email · X-User-Name
05
Request forwarded via Eureka load balancer
lb://user-service · lb://chat-service
06
Downstream service trusts gateway secret
GatewayAuthenticationFilter validates X-Gateway-Secret — no JWT parsing downstream
